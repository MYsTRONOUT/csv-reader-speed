A faster drop-in for csv-reader 1.0.0: the same answers, read with indexOf jumps instead of one character at a time.

## Run it

```sh
node main.ts
```

It reads `$MAKEFUN_INPUT_DIR/cases.json` (default `/input`) and writes `$MAKEFUN_OUTPUT_DIR/answers.json` (default `/output`).
